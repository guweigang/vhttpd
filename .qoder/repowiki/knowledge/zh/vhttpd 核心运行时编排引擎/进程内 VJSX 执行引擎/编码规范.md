- 所有公开的分发方法（如 `dispatch_http`）均采用“尝试-重试”模式，内部调用 `_once` 私有方法，并在捕获特定错误时根据 `inproc_vjsx_should_retry_dispatch` 逻辑进行有限次重试。
- Lane 资源获取遵循严格的 `acquire` / `defer release` 模式，确保在请求处理结束或发生异常时，Lane 的 `inflight` 计数能正确递减并触发后续任务调度。
- JS 对象交互中，所有从 `vjsx.Context` 获取的 `Value` 对象（如 `request_obj`, `js_runtime`）均在使用后立即调用 `.free()` 或通过 `defer` 块释放，防止 QuickJS 内存泄漏。
- 状态访问统一通过 `state.mu.@lock()` 和 `state.mu.unlock()` 保护，且在访问共享映射（如 `websocket_connection_lane_by_id`）时优先读取副本或使用 `or { default }` 语法确保线程安全。
