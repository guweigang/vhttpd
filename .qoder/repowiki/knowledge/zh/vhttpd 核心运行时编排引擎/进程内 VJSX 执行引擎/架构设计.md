- **核心架构**：采用 `InProcVjsxExecutor` 作为入口，内部管理 `VjsxExecutorState` 维护多个 `VjsxExecutionLane`（执行车道）。
- **并发模型**：每个 Lane 对应一个独立的 `VjsxLaneWorker` 线程和 `VjsxLaneHost`（JS 运行时实例），通过 Channel 接收任务，实现请求的物理隔离与并行处理。
- **请求分发**：支持 HTTP (`dispatch_http`)、WebSocket (`dispatch_websocket_event`) 和插件调用 (`call_plugin`)。HTTP 请求采用轮询获取空闲 Lane；WebSocket 支持基于 Affinity Key 的粘性路由和 Actor 模型序列化执行。
- **JS 桥接**：通过嵌入 `src/inproc_vjsx_http_facade.js` 提供标准化的 JS 运行时环境（`__vhttpd_create_runtime`, `__vhttpd_create_ctx`），实现 V 语言宿主与 JS 业务逻辑的数据交换。
- **生命周期管理**：包含启动钩子 (`run_startup_hooks`)、热更新签名探测 (`signature_refresh_loop`) 以及 Lane 的预热 (`warmup`) 和快照机制。
