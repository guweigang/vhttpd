- **分层架构**：模块内部按职责划分为 `Runtime`（宿主交互，如 `Manager`, `PhpWorker\Server`）、`App`（应用形态，如 `VSlim\Mcp\App`, `Feishu\BotApp`）和 `Integration`（协议适配，如 `Psr7Adapter`, `Stream\Factory`）。
- **调度机制**：通过 `VHttpd\Attribute\Dispatchable` 属性标记类，由 `PhpWorker\Server` 识别并分发至 HTTP、WebSocket、Stream 或 MCP 等不同处理通道。
- **入口设计**：`Manager` 负责外部进程生命周期控制，而 `VHttpd` 静态类提供基于 Unix Socket 的内部 Admin/Gateway 客户端访问。
- **证据文件**：`composer.json` 定义了 `VHttpd\` 和 `VSlim\` 命名空间映射；`PACKAGE_ROLE_MAP.md` 明确了 Model/Runtime/App/Integration 的角色分类。
