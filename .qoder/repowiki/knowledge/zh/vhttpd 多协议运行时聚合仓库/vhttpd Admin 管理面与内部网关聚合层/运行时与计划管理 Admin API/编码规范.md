- 每个 HTTP 处理函数都以 `@['/admin/...'; method]` 装饰器声明路由，并以 `(mut app App) admin_xxx(mut ctx Context)` 形式绑定到 `App` 上。
- 请求入口统一先调用 `admin_data_plane_request(ctx, path)` 构造 `req`，再用 `if !app.control_plane.admin.on_data_plane` 做开关检查，未启用时返回 404 文本响应。
- 成功响应一律通过 `admin_data_plane_json(mut app, mut ctx, METHOD, req, status, json.encode(body), { 'admin_endpoint': ... })` 包装，失败则返回 `json.encode(admin.AdminErrorResponse{ error: err.msg() })`。
- 可选查询参数使用 `ctx.query['key'] or { '' }` 配合 `.trim_space()` 解析，分页用 `admin.AdminQuery.limit/offset`，布尔值用 `parse_boolish`。
- 运行时快照通过 `app.build_admin_context()` 注入闭包式指标访问器，再由 `control_plane.stats_snapshot` / `runtime_snapshot` 统一聚合，避免在各 handler 中重复读取底层状态。
