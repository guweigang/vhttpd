- 所有对外错误信息统一使用 `inproc_vjsx_executor_` 前缀，便于上层按前缀匹配是否可重试。
- JSON 序列化采用 `json.encode(InProcVjsxRuntimeMeta{...})` 配合字段上的 `@[json: 'camelCase']` 注解，保持与 JS 侧约定的驼峰键名一致。
- 对 JS 对象的创建一律遵循 `defer { obj.free() }` 模式，确保 vjsx.Value 生命周期受控。
- 共享可变状态集中在 `VjsxExecutorState` 中，并通过 `state.mu.@lock()/unlock()` 保护，读取时先 clone 再释放锁。
- 长轮询/定时任务（如签名刷新）以独立 struct 方法集组织，并在循环首尾加 `signature_refresh_stop` 检查以支持优雅退出。
