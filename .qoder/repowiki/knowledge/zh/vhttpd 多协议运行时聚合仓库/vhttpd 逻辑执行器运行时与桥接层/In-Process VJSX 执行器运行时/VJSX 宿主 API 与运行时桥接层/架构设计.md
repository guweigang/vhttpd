本模块是 vhttpd 内嵌 VJSX 运行时的 Host 层，所有文件同属 `executor` 包，通过 `vjsx.Context.install_host_api` 将一组 `HostObjectField` 暴露给 JS 全局对象 `vhttpdHost`。

- 装配入口：`inproc_vjsx_host_api.v` 定义 `InProcVjsxHostApi.builder` 组装全部宿主方法，并通过 `install` 注册到 `vjsx.HostGlobalBinding{name: 'vhttpdHost'}`；`install_http_facade` 注入 HTTP facade 源码。
- 能力拆分：每个宿主能力独立一个文件，按职责划分——`inproc_vjsx_host_runtime_api.v`（emit/snapshot）、`inproc_vjsx_host_fs_api.v`（readTextFile/findCodexSessionPath）、`inproc_vjsx_host_http_fetch_api.v`（httpFetch）、`inproc_vjsx_host_dispatch_api.v`（bridgeDispatch/websocketDispatch）、`inproc_vjsx_host_session_store_api.v`（sessionStore）、`inproc_vjsx_host_config_api.v`（config）。
- 类型契约：`inproc_vjsx_host_api_types.v` 集中声明 JSON 编解码结构体（如 `InProcVjsxHostHttpFetchRequest/Response`、`InProcVjsxHostBridgeDispatchRequest`、`InProcVjsxHostSnapshotRequest` 等），作为 JS↔Go 的边界协议。
- 生命周期与加载：`inproc_vjsx_host_lifecycle.v` 的 `ensure_lane_host` 协调 `VjsxRuntimeSessionFactory` 创建 session、安装 TS 运行时、构建/导入模块或脚本入口、探测 `http`/`websocket`/`websocket_upstream`/`plugin`/`openai` 处理器，并将结果写入 `state.hosts[idx]`；`vjsx_host_loader.v` 提供 `load_entry`、`entry_runs_as_module`、`lane_temp_root` 等路径/缓存策略；`vjsx_host_signature.v` 基于 include/exclude glob + FNV1a 计算 source signature，驱动 dirty 检测与 lane 热重启。
- 依赖方向：本模块只向上依赖 `upstream.transport`、`net.http`、`os`、`json` 以及外部 `vjsx`、`vjsx.runtimejs`，不反向被 executor 核心以外的包引用，属于 executor 内部的“宿主适配”子层。
