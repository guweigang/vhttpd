本模块是 relay 子系统的运行时内核，按职责拆分为三个文件：
- `runtime.v`：定义 `Runtime` 聚合根，持有 `descriptors`（从 `runtime_plan.RuntimePlan` 解析的拓扑）、`agents`（Agent 连接态映射）、以及 `ChannelRegistry`/`SessionRegistry`/`CarrierRegistry` 三个子注册表；对外暴露 `ensure_agent`、`mark_agent_*`、`handle_frame`、`route_session_frame`、`open_session_endpoint`、`carrier_dispatch_plan`、`snapshot` 等命令式方法，自身不直接操作底层 IO，仅做协调。
- `agent_state.v`：纯函数式无副作用的状态机，以不可变更新模式实现 `AgentConnectionState`（disconnected → connecting → registered / backoff → closed），通过 `begin_connect`/`mark_registered`/`mark_failed`/`close` 返回新 `AgentState`，并提供指数退避 `reconnect_delay_ms` 策略。
- `agent_handshake.v`：将 `WireFrame.kind == .hello_ack` 或 `.error` 转换为 `AgentHandshakeOutcome`，内部调用 `Runtime.mark_agent_registered`/`mark_agent_failed` 驱动状态机，并附带 trace/frame 元数据供上层事件上报。
依赖方向：`agent_handshake` → `Runtime` → `agent_state` + 子注册表；`runtime` 还依赖 `dispatch`（用于 `DeliveryProjection`）和 `runtime_plan`（描述符来源）。测试文件 `*_test.v` 分别覆盖 `Runtime` 构造/快照与握手流程。
