- **分层架构**：采用四层设计，包括协议入口层（HTTP/WebSocket/Stream/MCP）、传输编排层（Worker Frame/Dispatch）、运行时状态层（Admin Plane）及 PHP Worker 桥接层。
- **核心模块映射**：`main.v` 负责顶层路由；`worker_transport.v` 定义长度前缀 JSON 帧契约；`stream_runtime.v` 与 `upstream_runtime.v` 分别处理下游流生命周期与上游计划执行；`mcp_runtime.v` 承载 MCP Streamable HTTP 会话。
- **Provider 封装模式**：通过 `Provider` 接口（init/start/stop/snapshot）实现飞书（Feishu）、Codex 等上游协议的插件化集成，状态收敛于专属 Runtime Struct。
- **证据文件**：`docs/RUNTIME_MODULE_MAP.md` 定义了源码职责边界；`docs/transport_contract.md` 规定了 v1 版 Worker 通信帧结构；`articles/10-architecture.md` 阐述了整体运行时模型。
