模块由两个同属 `dispatch` 包的源文件组成：
- `http.v` 定义入站数据结构 `HttpIngressRequest` 以及将其转换为内部统一 `Exchange` 的入口函数 `http_request_exchange`，同时负责将 header key 统一小写。
- `http_match.v` 定义匹配描述结构体 `HttpMatch` 与核心匹配器 `http_exchange_matches`，按顺序校验 exchange.kind、method、host、path、query、headers；路径匹配通过 `match_path_pattern` 支持精确、前缀 `*`、后缀 `*` 与全通配 `*`，其余字段使用 `match_string_list` / `match_value_pattern` 做大小写不敏感或精确匹配。
- `route_rule_test.v` 作为 `main` 包的可执行测试，不仅验证上述匹配逻辑，还覆盖更高层的 `RuntimeRouteRule`、`HttpRoutingRuntime`、静态资源根优先级、响应缓存 bypass 原因、上传完成事件交换构造等集成场景，是路由规则行为的单一事实来源。
依赖方向单向：测试 → dispatch 包；dispatch 包之间无循环，仅暴露 `HttpIngressRequest`、`HttpMatch`、`http_exchange_matches` 等公开接口给上层路由调度层。
