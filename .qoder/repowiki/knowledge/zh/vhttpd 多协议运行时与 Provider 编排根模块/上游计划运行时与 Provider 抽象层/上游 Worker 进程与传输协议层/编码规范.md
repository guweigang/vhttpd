- 跨进程 JSON 帧一律用 struct + @[json: 'xxx'] 字段标签声明，并在同名 struct 上提供 try_decode_xxx 辅助方法做 mode/event 校验后再返回。
- 网络 I/O 读写封装在 WorkerFrameCodec.read_exact / read_bytes / write 等方法中，调用方通过 read_frame / write_frame 便捷函数访问。
- HTTP 到 worker 的请求数据通过 WorkerHttpRequestCodec 命名空间下的 encode_request / header_map_from_request / cookie_map_from_request / server_map_from_request 等函数逐步组装成 WorkerRequestPayload。
- 对外暴露的工厂函数采用 StructName.from_xxx(...) 或 StructName.for_xxx(...) 形式，内部再委托带 provider 后缀的版本完成差异化处理。
- 子进程管理统一走 ManagedWorker.start/build_slot/stop 流程，停止时先对 -pid 发 SIGTERM 再发 SIGKILL，并使用 restart_backoff_ms 指数退避。
