本模块由三个独立的 V 源文件组成，分别承担两类职责：
- `admin_schema_runtime.v`：纯数据定义层，通过 `AdminSchemaCatalog` 聚合 `listeners/resources/engines/adapters/transforms/policies/providers/pipelines/relays` 九个 domain，每个 domain 下以 `AdminSchemaKind` 描述 kind 及其字段（`schema_field` 构造），并暴露 `admin_schema_catalog()`、`admin_schema_domain()`、`admin_schema_kind()` 供上层查询。
- `admin_apps_runtime.v`：基于 `runtime_plan.RuntimePlan` 构建 AdminAppsSnapshot 的 Builder 模式实现，`AdminAppSummary` 按 app 维度聚合 listeners/pipelines/engines/adapters/resources/providers/relays，并通过 `app_id_from_*` 系列方法把子项归属到应用；`finish()` 中统一排序并计算 counts/diagnostics。
- `admin_provider_runtime.v`：两个 HTTP 路由处理器（`@['/admin/providers/specs'; get]`、`@['/admin/providers/runtimes'; get]`），在控制平面启用时转发到 data plane 并以 JSON 返回 provider 的 schema 与运行时快照。
依赖方向单向：provider 路由 → runtime snapshot → schema catalog；对外仅暴露 `pub fn` 和带 `@` 注解的路由函数，内部结构体与方法默认私有。
