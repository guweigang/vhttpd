- 对共享状态 `e.state` 的所有读写都显式加锁 `state.mu.@lock()` / `unlock()`，并在失败回退路径中重复加锁修改后再解锁，避免遗漏恢复逻辑。
- 任务选择键根据 `task.actor_serialized` 分支取 `actor_key` 或 `affinity_key`，同一份代码在 enqueue、schedule、finish 三处保持一致的键计算模式。
- 对外暴露的阻塞操作统一使用 `select { _ := <-ch; <timeout_const> }` 模式，并以带前缀的错误字符串（如 `inproc_vjsx_executor_lane_task_timeout`）返回，便于上层诊断。
- 可空指针访问一律用 `or { ... }` 默认值包裹（如 `websocket_mailbox_by_key[key] or { []... }`），而非先判 nil 再取值，保持函数式风格。
