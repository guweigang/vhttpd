本模块为纯文档仓库，按用途分为两层：
- `docs/`：面向开发与重构的内部设计文档，以 Markdown 形式记录当前架构基线（ARCHITECTURE_REFACTOR_BASELINE.md）、各子系统演进计划（MCP_*、WEBSOCKET_*、FEISHU_*、STREAM_*、UPSTREAM_*、PROTOCOL_PIPELINE_* 等）以及运行时契约与运行手册（RUNTIME_MODULE_MAP.md、COMMAND_CONTRACT_INVENTORY.md、INPROC_VJSX_RUNBOOK.md、MCP_RUNBOOK.md 等），依赖方向由高层计划文件引用底层契约文件。
- `articles/`：面向外部读者的 14 篇结构化教程，通过 README.md 中的“叙事主线”统一产品定位（transport runtime 而非 HTTP 服务器），并按“定位→入门→核心功能→TypeScript 插件→架构与高级→案例与未来”六部分编排，每篇文章编号前缀保证阅读顺序。
两个子目录之间无代码耦合，仅共享同一项目概念体系（Provider、Kernel、Control/Data Plane、Worker 池、Stream phase 等）。
