- **TS 应用启动**：需设置飞书凭证环境变量（`FEISHU_APP_ID` 等），执行 `./vhttpd --config examples/codexbot-app-ts/codexbot.toml`。
- **PHP 测试执行**：在 `examples/codexbot-app` 目录下运行 `composer install` 后执行 `composer test`。
- **多场景演示**：通过 `examples/config/*.toml` 配合根目录 `make serve` 或 `./vhttpd --config` 快速切换 Ollama 代理、MCP Server 或 WebSocket Echo 等场景。
