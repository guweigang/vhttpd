本模块是只读示例集合，按运行形态分为三类：
- 顶层 PHP 单文件入口（hello-app.php、mcp-app.php、ai-stream-app.php、ollama-proxy-app.php、stream-bench-app.php、stream-dispatch-app.php、websocket_echo_app.php、feishu-bot-mcp-app.php）配合 `examples/config/*.toml`，通过 `./vhttpd --config ...` 直接驱动 vslim PHP worker；`run_demo.sh` 封装 make + curl 的一键演示流程。
- 独立子项目目录：`codexbot-app/`（PHP Pest 测试套件，入口 `app.php` → `CodexBot\AppRuntime`）、`codexbot-app-ts/`（TypeScript-first vjsx bot，入口 `app.mts` 暴露 `startup/app_startup/http/websocket_upstream` 钩子，组合根在 `lib/bot-runtime.mjs`，协议类型 vendored 在 `codex/ts`，Feishu 边界在 `feishu/`）、`paseo-relay/`（vjsx relay skeleton）、`ws-min/`（最小 WebSocket 示例）。
- 框架集成模板：`symfony/`、`laravel/`、`wordpress/` 各自带 `composer.json` + `app.php` + `README.md`，由对应 TOML 配置挂载到 vhttpd 进程。
依赖方向单向：示例代码仅消费 vhttpd/vjsx 运行时 API，不反向依赖核心源码；每个子项目自包含 README 说明启动方式与环境变量。
