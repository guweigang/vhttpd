- 每个功能文件独立声明 `module main`，通过同名 `pub fn (mut app App) mcp_*` 方法暴露给 veb 路由，内部再委托给私有 `mcp_handle_*_http` 函数。
- 对 `app.protocols.mcp` 的所有读写都显式持有 `mu.@lock()` 并在末尾 `unlock()`（常用 `defer { s.mu.unlock() }` 模式），确保 sessions map 并发安全。
- HTTP 错误路径统一走 `mcp_json_response`，设置 `content-type: application/json; charset=utf-8` 并通过 `x-vhttpd-error-class` 头传递错误分类。
- SSE 推送采用固定帧格式 `event: message\ndata: ${raw}\n\n`，由 `Session.write_sse_json` 集中实现，避免在各处重复拼接。
- 客户端能力检测通过字符串包含 `"sampling"` 与 `"method":"sampling/createMessage"` 判断，而非完整 JSON 解析，配合 `normalize_sampling_capability_policy` 归一化 drop/error/warn 三种策略。
