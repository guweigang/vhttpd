- 所有 in-process 子模块以 `inproc_vjsx_` 前缀命名，便于与 socket_worker/php_cgi 等外部执行器区分
- 跨模块共享的运行时结构体集中在 `runtime_core_shared_types.v`，其他子模块仅 import 不重复定义
- 宿主 API 采用 `*_host_api*.v` + `*_host_*_api.v` 分层：接口类型在前、具体实现在后，统一通过 `vjsx_host_loader.v` 注册
- 配置解析走 `registry.v` 中 `resolve_*_config` 系列函数，由 `BuiltinLogicExecutorSpec.config_surface` 驱动 flag 映射
