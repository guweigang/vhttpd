- 所有跨 goroutine 的请求都采用「构造 slot + 写入专用 channel + select(done_ch | timeout) + 锁保护 slot 字段」的模式，确保同步等待且可超时。
- 错误路径统一先 `InProcVjsxError.normalize_message(err.msg(), 'inproc_vjsx_executor_xxx')` 再填充 `slot.result.ok=false` 并置 `ready=true`，最后 `task.done <- true` 返回。
- 对 `e.state` 的访问一律先判空，再用 `state.mu.@lock()/unlock()` 包裹，并在需要时 `defer state.mu.unlock()` 保证并发安全。
- Worker 侧对 `InProcVjsxExecutor` 的调用全部通过 `worker_executor := InProcVjsxExecutor{state: unsafe { state }}` 复制一份引用，避免直接持有外部可变状态。
- WebSocket 任务在 `defer` 中根据 `actor_serialized` 或 `WebSocketAffinityPolicy.should_pin_lane` 决定是否调用 `finish_websocket_mailbox_task`，随后总是 `release_lane` 归还占用。
