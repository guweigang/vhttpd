本模块以 `registry.v` + `types.v` 为对外契约：`BuiltinLogicExecutorSpec` 声明内置 executor（noop/php/socket_worker/inproc_vjsx），由 `runtime_selection.v` 按 kind 选择并返回 `ExecutorRuntimeSelection`；inproc_vjsx 分支通过 `ExecutorFactory.new_inproc` 回调构造 `VjsxRuntimeFacadeConfig`，再交由子模块分层实现。

- 启动期：`bootstrap_startup` 解析 CLI 与入口、加载签名、触发 app/lane 启动钩子，产出可被 host 消费的初始化结果。
- 运行期核心：`lanes_host_pool_workers` 提供 lane 池与多 goroutine worker，host 侧通过 channel 派发任务并收集响应；`lanes_state_context` 维护 lane 健康、请求会话上下文与唤醒时间戳；`sessions_lifecycle` 管理进程内 session、lane 多通道路由、WebSocket 亲和与 Codex 调试定位。
- 宿主能力：`host_apis` 暴露 emit/snapshot/sessionStore/config/fs/http/fetch 等桥接给 JS，同时承担应用入口加载与生命周期编排。
- 协议扩展：`plugins_streaming` 处理同步/流式插件调用并将 vjsx.Value 编码为 transport.WorkerResponse；`websocket_layer` 把 WS 帧直接路由到 VJSX Actor/亲和键，桥接到 JS 完成请求-响应。
- 共享基础设施：`runtime_core_shared_types` 集中定义 Request/Response/Event/Snapshot/Signature 等跨文件类型，所有子模块复用同一份载荷与错误模型，避免重复编解码。
