- 所有宿主能力均以 `runtime.set(name, ctx.js_function(...))` 的形式注册到 JS runtime 对象上，形成统一的 API 暴露模式。
- JS 函数参数采用 `args.len > N` 分支配合 `dup_value()` 或默认值实现可选参数，并在缺失时回退到 `ctx.js_undefined()` 或空对象。
- 通过全局宿主函数 `vhttpdHost.<method>` 访问宿主页面的方式固定为：`ctx.js_global('vhttpdHost')` → 判空/判对象/判 has → `defer host_fn.free()` → `ctx.call(host_fn, payload)` → 解析响应。
- 跨语言请求体一律使用 `InProcVjsxHost*Request` 结构体经 `json.encode` 序列化后作为字符串参数传给宿主，响应则用对应的 `InProcVjsxHost*Response` 反序列化。
- 日志类宿主函数 (`log`/`warn`/`error`) 统一输出 `[vhttpd] ${lane_id} ${request_id} ${trace_id} ${args}` 格式，并通过 `println`/`eprintln` 区分级别。
