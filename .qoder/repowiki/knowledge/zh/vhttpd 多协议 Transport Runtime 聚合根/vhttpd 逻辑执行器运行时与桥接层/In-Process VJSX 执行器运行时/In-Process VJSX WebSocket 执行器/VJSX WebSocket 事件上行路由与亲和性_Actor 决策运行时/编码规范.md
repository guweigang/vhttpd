- 每个对外 dispatch 入口遵循固定模板：`bootstrap_placeholder` → `ensure_lane_host` → `run_startup_hooks` → `activate_lane_request_context` → 调用 JS 入口 → `clear_lane_request_context` → `record_lane_success/error`，错误时记录 lane 指标后返回错误。
- 所有 JS 对象（runtime/frame/result/resolved/normalize_fn 等）在获取后立即以 `defer { obj.free() }` 释放，避免 V8 句柄泄漏。
- 缺失可选 handler（如 `websocket_upstream`、`websocket_affinity`、`websocket_actor`）时不抛错，而是返回语义化的空响应结构体（`handled=false`、`decision={}` 等）。
- 对可重试的上行调用使用 `for attempt in 0 .. inproc_vjsx_dispatch_retry_attempts` 循环，并在失败时通过 `InProcVjsxError.should_retry_dispatch` 判断是否继续重试。
- 错误信息统一使用 `InProcVjsxError.context_message(ctx, msg, 'inproc_vjsx_executor_...')` 包裹上下文前缀，保持错误码命名一致。
