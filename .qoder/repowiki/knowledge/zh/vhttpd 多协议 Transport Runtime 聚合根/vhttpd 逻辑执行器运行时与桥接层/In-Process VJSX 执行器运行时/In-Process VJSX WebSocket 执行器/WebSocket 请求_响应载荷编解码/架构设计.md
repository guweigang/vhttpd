本模块由三个职责清晰的文件组成，共同构成 WebSocket 在 VJSX 执行器内与外部 transport 层之间的适配边界：
- `inproc_vjsx_websocket_request.v`：纯函数工具集，从 `transport.WorkerWebSocketFrame` 派生 `server_map`（host/port/remote_addr/url）和 `scheme_from_frame`（优先 x-forwarded-proto/x-scheme，否则 ws），并负责将 path+query 规范化为目标 URL。
- `inproc_vjsx_websocket_runtime_payload.v`：作为 `InProcVjsxExecutor` 的方法，把 `VjsxExecutionLane` + frame/upstream request 组装成 `InProcVjsxRuntimeMeta` JSON 字符串，并提供 `build_websocket_frame_bundle_payload` 将原始 frame 与 runtime meta 打包为 `InProcVjsxWebSocketFrameBundle` 供上层分发。
- `inproc_vjsx_websocket_response_codec.v`：定义 `InProcVjsxWebSocketResult` / `InProcVjsxWebSocketUpstreamResult` 两个中间结构体，实现 `websocket_from_json` 与 `websocket_upstream_from_js_value`，将 VJSX handler 返回的 JSON 值反序列化为 `transport.WorkerWebSocketDispatchResponse` / `WorkerWebSocketUpstreamDispatchResponse`；对空/undefined/null 返回值统一降级为 accepted=false 的空结果，并通过 `websocket_handler_missing_result` 生成默认缺失响应。
依赖方向单向：runtime_payload → request（复用 server_map/scheme），response_codec 仅消费 transport 类型，不反向依赖 payload 构建逻辑。
