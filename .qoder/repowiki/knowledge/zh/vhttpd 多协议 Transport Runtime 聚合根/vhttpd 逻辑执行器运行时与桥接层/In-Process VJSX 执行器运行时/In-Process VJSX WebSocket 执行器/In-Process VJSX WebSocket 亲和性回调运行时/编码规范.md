- 所有对外暴露的状态读写都先取 `e.state` 副本，再用 `state.mu.@lock()` / `defer state.mu.unlock()` 保护，避免持有锁期间做 IO 或调用外部函数。
- 错误码统一采用 `inproc_vjsx_executor_*` 前缀的字符串常量（如 `inproc_vjsx_executor_state_missing`、`inproc_vjsx_executor_websocket_affinity_timeout`），便于上层分类处理。
- 对可选对象（`e.state`、`app_ref`）一律用 `isnil(...)` 显式检查并在缺失时返回结构化错误，而非 panic。
- JS 侧全局函数通过 `ctx.js_global(...)` 获取后立刻 `defer free()`，且在使用前用 `is_function()` / `is_undefined()` 校验，失败路径统一包装为带上下文的错误码。
- 亲和性 key 为空时的降级逻辑遵循同一模板：若 `config.enabled && fallback == 'reject'` 则返回 `inproc_vjsx_executor_websocket_affinity_key_missing`，否则走无 key 分支继续处理。
