本模块以 `inproc_vjsx_websocket_types.v` 为共享契约，围绕「帧→Actor→JS 调用→响应」流水线组织子模块：
- 接入层：`js_integration` 暴露 runtime/sessionStore/dispatch API 给宿主与 JS；`affinity_callback` 负责连接级亲和回调与结果归一化。
- 决策层：`actor_policy` 基于帧来源选择 Actor/Lane，`event_upstream_lane` 在 lane 内同步派发上游调用并桥接 affinity/actor 决策。
- 调度层：`types_mailbox_awaiter` 提供按 Actor/亲和键分发的消息队列、Lane 绑定与 Awaiter，保证串行化与超时。
- 编解码层：`request_response_payload` 统一帧↔运行时元数据与 JS 返回值之间的 payload 构建。
所有子模块通过同一份类型定义与 dispatch/response 协议耦合，形成从 WebSocket 帧进入、经策略与队列调度、最终落盘到 JS 引擎的完整 in-process 路径。
