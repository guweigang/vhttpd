模块按职责拆分为三个文件，均属于 `executor` 包：
- `inproc_vjsx_websocket_policy.v`：定义 `WebSocketAffinityPolicy` 与 `WebSocketAffinityDecision`，负责从请求帧（header / path_param / query）解析亲和 key 与 priority，并判断是否应 pin 到固定 lane。
- `inproc_vjsx_websocket_actor_policy.v`：定义 `WebSocketActorPolicy` 与 `WebSocketActorDecision`，在亲和策略基础上扩展 class_name、persist 字段，并提供 `connection_cache`、`app`、`header`、`metadata`、`query` 等 source 类型的归一化与取值逻辑，同时复用 `WebSocketAffinityPolicy.priority_from_string`。
- `inproc_vjsx_websocket_actor_runtime.v`：作为对外入口，挂载在 `InProcVjsxExecutor` 上，实现 `resolve_websocket_actor` 主流程——按配置顺序遍历 sources（先查 connection_cache，再调用 app 钩子，最后回退到静态 source），通过 channel + select 向目标 lane 派发 `InProcVjsxLaneAffinityTask` 获取 actor 决策，并在 `e.state` 中维护 `websocket_connection_actor_key_by_id` / `class_by_id` 以支持连接级缓存；提供 `cache_websocket_actor` / `release_websocket_actor` 供上层在连接建立/关闭时调用。
依赖方向单向：runtime → policy（actor_policy → affinity_policy），不反向依赖 executor 其他组件。
