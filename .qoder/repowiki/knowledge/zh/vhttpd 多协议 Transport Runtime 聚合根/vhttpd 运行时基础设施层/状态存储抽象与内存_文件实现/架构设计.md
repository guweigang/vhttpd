模块由两个独立 V 包组成：
- `state_store`：定义泛型接口 `StateStore[T]`（get/set/set_with_ttl/delete/exists/keys/list/patch/prune_expired/clear），并通过 `MemoryStateStore[T]` + `StoredValue[T]` 在进程内 map 中实现，使用 `sync.Mutex` 保证并发安全；通过内部 `MemoryStateStoreClock` 抽象时间源，支持 TTL 过期检测与惰性清理；另为 string 类型提供 compare_and_swap_set_with_ttl / compare_and_swap_delete 原语。
- `admin_state_store`：面向管理员的轻量持久化后端，`FileStore` 将 namespace/key 映射到 `<root>/<namespace>/<key>.json` 文件，写入走 `atomic_write`（先写 `.tmp` 再 mv）保证原子性；同时维护 `<root>/events.jsonl` 追加式事件日志，每条事件为带 id/type/at_unix/fields 的 JSON 行。
依赖方向单向：上层 HTTP 路由或业务逻辑依赖这两个包的 pub 接口，二者互不引用。
