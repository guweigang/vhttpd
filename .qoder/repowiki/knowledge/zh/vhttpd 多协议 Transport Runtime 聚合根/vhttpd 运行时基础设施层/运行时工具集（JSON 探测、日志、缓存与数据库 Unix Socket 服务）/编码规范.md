- 所有对外暴露的运行时组件（cachex.Runtime、dbx.Runtime、logging.RuntimeLogger）均以 struct 方法形式组织，并通过 `snapshot_json` 返回可序列化的 Snapshot 供监控端消费。
- Unix Socket 服务统一采用 4 字节大端长度前缀帧协议（`FrameCodec.read/write`），请求/响应均为 JSON 编码的 Request/Response 结构体。
- 错误响应通过工厂函数构造（如 `Response.error`/`Response.ok`/`Response.pong`），而非直接字面量赋值，保证 ok/error/driver 等字段一致性。
- 跨驱动分支（mysql vs pgsql）统一用 `match driver` 分发，并在 else 分支返回 `error('unsupported_driver')`，保持两种实现的对称性。
- 运行时状态变更（started、listener、stop_requested 等）一律先加 `rt.mu.@lock()` 再修改，并用 defer/unlock 配对释放。
- 配置项优先从环境变量或参数中取非空值，否则回退到内置默认值（如 socket 路径、端口、pool_size、driver 默认 mysql）。
