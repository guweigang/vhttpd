本模块为纯前端静态资源，由 vhttpd 自身通过 `[listeners.admin_ui]` + `[control]` 暴露到 `127.0.0.1:20210`（见 `admin/admin.toml`），并通过 `include` 聚合 WordPress 与 paseo-relay 示例配置。

- 入口文件：`ui/index.html` 定义 shell 布局（侧边栏导航 + 多 view 面板）并加载 `style.css` 与 `app.js`。
- 状态机：`app.js` 维护单一全局 `state`（activeView / data / errors / history / draftId 等），所有视图函数按 `selectView(name)` 切换 `.view.hidden` 类名渲染。
- 数据层：集中式 `endpoints` 映射表驱动 `refresh()` 并发 `fetch('/admin/runtime' | '/admin/runtime/graph' | '/admin/config/files' | '/admin/source/files' | '/admin/schema' | '/admin/drafts' | '/admin/events?limit=80' | '/admin/stats')`，统一经 `authHeaders()` 注入 `x-vhttpd-admin-token` 请求头，错误归入 `state.errors` 并在顶部 status bar 汇总显示。
- 视图组件：每个 `renderXxx()` 对应一个 `<section id="view-xxx">`，负责把 `state.data.xxx` 转成 HTML 片段；图表使用内联 SVG（sparkline、flow topology）而非第三方库。
- 编辑器子系统：通过 `editorParts(prefix)` 复用 textarea + highlight pre + lines pre 的三层结构，支持 TOML/TypeScript/JSON/text 语法高亮与滚动同步，用于 Drafts 与 Source Editor 两个场景。
- 依赖方向：仅依赖浏览器原生 fetch/DOM API，不引入任何框架或打包产物；样式全部内聚在 `style.css`，无外部 CDN 依赖。
