- DOM 访问统一通过 `$ = (id) => document.getElementById(id)` 短函数封装，避免直接调用 getElementById。
- 所有用户可控字符串在插入 DOM 前一律经 `esc()` 进行 HTML 实体转义，防止 XSS。
- 后端返回字段存在多种命名变体时，用 `nestedNumber` / 双问号回退链（如 `stats.requests_total ?? stats.http_requests_total`）兼容历史格式。
- 任意可能为 undefined 的后端集合都用 `asArray(value)` 包裹后再遍历，保证渲染函数对缺失字段鲁棒。
- 视图切换通过 `data-view` 属性 + `aria-selected` 同步实现，模板与逻辑解耦，新增页面只需添加按钮和 `<section id="view-xxx">`。
- 草稿/源文件编辑操作遵循 open → save(PUT) → validate(POST) → diff(GET) → publish(POST) → apply(POST) 的统一 REST 风格，错误结果以 `{ ok, error }` 对象形式展示在对应 result 区域。
