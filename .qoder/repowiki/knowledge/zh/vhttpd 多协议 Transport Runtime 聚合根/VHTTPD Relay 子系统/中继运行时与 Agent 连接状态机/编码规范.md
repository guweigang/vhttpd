- 状态变更采用不可变更新：所有 `AgentState` 方法返回新的结构体副本（使用 `...state` 展开），由调用方写回 `rt.agents[relay_id]`，避免就地修改。
- 错误传播统一通过 `!` 返回值 + `or { return error(...) }` 短路，并在失败路径中包装带前缀的错误码（如 `relay_runtime_unknown_relay:`、`relay_agent_registration_rejected`）。
- 对外 API 以 `(mut rt Runtime)` 接收可变接收者，但实际只委托给内部注册表或调用纯函数，保持 `Runtime` 作为薄协调层。
- 时间戳统一以毫秒级 `i64 now_ms` 参数传入，状态机内部比较 `next_attempt_at_ms >= now_ms` 判断重连时机，避免依赖全局时钟。
