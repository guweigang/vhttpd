- 对外 API 以纯函数形式暴露，输入为结构体或 registry 视图，输出为新结构体，不持有可变状态。
- WireFrame 元数据统一使用字符串键值对 map[string]string 传递，缺失字段通过 `or { default }` 提供回退值。
- 错误处理采用 V 的错误传播风格：验证函数返回 `!` 错误，调用处用 `!` 短路；业务拒绝则返回带 `accepted: false` + `error` 字段的 Result 结构体。
- 枚举/kind 映射集中放在同名 `*_from_*` 辅助函数中（如 `relay_exchange_kind_from_frame`、`relay_exchange_kind_from_string`），避免在调用点散落 match 分支。
