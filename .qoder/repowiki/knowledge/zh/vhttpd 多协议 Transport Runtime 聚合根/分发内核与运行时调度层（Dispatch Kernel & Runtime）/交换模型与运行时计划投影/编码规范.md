- 对外导出函数采用 from_plan 后缀命名（如 adapter_descriptor_from_plan、ingress_descriptor_from_listener_plan、pipeline_descriptor_from_plan_with_adapters），形成“从声明计划投影为运行期描述符”的统一 API 风格。
- 能力推导通过独立的 fn xxx_capabilities(kind) Capabilities 函数集中处理，再以 match kind.trim_space().to_lower() { ... } else { default } 分支给出最小默认集，避免在调用处重复判断。
- 对同一逻辑提供带 adapters/transforms 参数的重载版本（如 pipeline_descriptor_from_plan 与 pipeline_descriptor_from_plan_with_adapters/with_runtime_descriptors），用于逐步增强描述符所需信息。
- 错误/诊断路径成对暴露字符串版与 PlanDiagnostic 版（pipeline_capability_errors_from_plan / pipeline_capability_diagnostics_from_plan / issues_to_diagnostics），上层按需选择返回形式。
