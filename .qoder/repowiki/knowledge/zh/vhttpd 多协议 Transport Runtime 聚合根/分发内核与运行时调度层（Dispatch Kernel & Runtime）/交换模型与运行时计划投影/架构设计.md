本模块是调度层的数据契约与静态分析入口，按职责分为三层：
- exchange.v：声明所有跨阶段共享的类型——ExchangeIdentity、ExchangeKind、ExchangePayload（Empty/Error/Event/Request/Response/Session/Stream 联合）、Capabilities、TransformAction 及 Transformer/RuntimeServices 接口，构成管道各节点之间的唯一通信协议。
- plan_projection.v：纯函数集合，把 runtime_plan.RuntimePlan 投影为 IngressDescriptor/TransformDescriptor/AdapterDescriptor/PipelineDescriptor 等运行期描述符，并实现能力匹配校验（listener_capabilities/relay_capabilities/provider_capabilities/transform_capabilities + missing_capabilities）以及 HTTP match 提取与匹配（match_basic_http_pipeline*）。
- adapter_projection.v：将 runtime_plan.AdapterPlan 映射为 AdapterDescriptor 与 EgressAdapter（fixed-response/reject/relay-delivery），并通过 adapter_descriptor_from_plan 统一注入到 ingress_descriptors_from_plan 中作为事件入口。
依赖方向单向：plan_projection.v 与 adapter_projection.v 均 import runtime_plan，exchange.v 不依赖任何其它 dispatch 子模块，被上层调度器消费以完成从声明计划到运行期管道的构建。
