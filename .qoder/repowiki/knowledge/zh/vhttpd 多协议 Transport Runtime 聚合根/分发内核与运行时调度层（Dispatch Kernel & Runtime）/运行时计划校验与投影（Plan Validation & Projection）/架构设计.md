本模块由两个互补的 V 文件组成：
- `plan_validation.v`：只暴露 `validate_runtime_plan_projection` / `runtime_plan_projection_diagnostics` 两个对外入口，内部组合两类诊断——来自 `pipeline_capability_issues_from_plan` 的能力不匹配问题与来自 `pipeline_projection_reference_diagnostics_from_plan` 的引用缺失错误（ingress/transforms/egress 指向不存在或类型错误的资源），并通过 `pipeline_projection_ingress_exists` / `pipeline_projection_egress_exists` 按 domain 分派判定逻辑。
- `plan_projection_test.v`：测试覆盖位于同包内 `plan_projection.v` 中的投影函数（`ingress_descriptors_from_plan`、`transform_descriptor_from_plan`、`terminal_descriptor`、`pipeline_descriptor_from_plan*`、`listener_pipeline_descriptors`、`match_basic_http_pipeline*`、`pipeline_transform_capability_errors/issues` 等），这些函数把 `RuntimePlan` 映射到 `IngressDescriptor`/`AdapterDescriptor`/`TransformDescriptor`/`TerminalDescriptor`/`PipelineDescriptor` 等运行时描述符集，并计算 required capabilities。
依赖方向单向：本模块仅 import `runtime_plan`，被上层 dispatch 调度器消费；测试通过构造最小 `RuntimePlan` 断言投影结果与诊断码（如 `pipeline_capability_mismatch`、`pipeline_projection_missing_*`）。
