- 运行时入口文件统一声明 `module main` 并使用 `@['/path'; method]` 注解注册 HTTP 路由，避免显式路由表维护。
- 所有 HTTP 响应经由 `feishu_http_runtime.v` 中的 `feishu_json_response` / `feishu_admin_error` 构造，统一注入 `provider=feishu` 元数据与请求标识。
- 对 `FeishuState` 的写操作遵循 `ensure(name)` → 修改字段 → `update_runtime(name, runtime)` 三段式模式，并在方法内持有 `s.mu.@lock()` 保护。
- 事件入站路径（回调与 WebSocket）先调用 `RuntimeEventSnapshot.summary_from_payload` 抽取摘要，再构造完整 `RuntimeEventSnapshot` 写入 `push_event`，随后才进入分发逻辑。
- Card Bridge 的 WebSocket C 回调一律写成自由函数（`_cb` 后缀）并通过 `unsafe { &App(ref) }` 取回上下文，注释说明是为规避 C 符号未声明问题。
