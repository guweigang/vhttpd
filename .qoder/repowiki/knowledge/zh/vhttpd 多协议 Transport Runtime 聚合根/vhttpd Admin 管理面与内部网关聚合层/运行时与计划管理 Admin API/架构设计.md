模块由三个职责清晰的 V 文件组成：
- `admin_runtime_graph.v`：定义 `AdminRuntimeGraph`（节点+边）数据结构与 `AdminRuntimeGraphBuilder` 构建器，遍历 `app.plan`（来自 `runtime_plan` 包）中的 listeners/resources/adapters/transforms/policies/providers/relays/pipelines，按 domain:id 规范化 ref 并去重生成有向图。
- `admin_runtime_context.v`：通过 `build_admin_context()` 把 `App` 的统计指标、引擎队列、websocket/mcp/upstreams/relay 等子系统的 snapshot 方法桥接成 `admin.RuntimeContext` 闭包集合，供 `control_plane.stats_snapshot` / `control_plane.runtime_snapshot` 消费；同时提供 pipeline/relay/stats 的专用 snapshot 转换函数。
- `admin_runtime.v`：注册所有 `/admin/*` GET/POST/PUT/DELETE 路由，统一走 `admin_data_plane_request` + `admin_data_plane_json/text` 包装，先校验 `app.control_plane.admin.on_data_plane`，再调用 `app.admin_*` 或子系统 snapshot 返回 JSON；错误路径一律返回 `admin.AdminErrorResponse`。
依赖方向单向：`admin_runtime.v` → `admin_runtime_context.v` → `admin.RuntimeContext` → `control_plane`；`admin_runtime_graph.v` 仅依赖 `runtime_plan` 与自身结构体，不反向依赖上下文。
