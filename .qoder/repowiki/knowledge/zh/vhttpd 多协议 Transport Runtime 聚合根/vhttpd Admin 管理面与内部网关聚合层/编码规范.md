- HTTP handler 使用 `@['/admin/...'; get|post]` veb 注解声明路由，并在函数体开头调用 `admin_data_plane_request(ctx, path)` 构造请求上下文。
- 所有 /admin/* 接口在进入业务逻辑前检查 `app.control_plane.admin.on_data_plane`，未启用时返回 404 文本响应而非 JSON。
- 查询参数统一走 `admin.AdminQuery.limit/offset/parse_boolish` 解析，避免在各 handler 内重复实现分页与布尔解析。
- 错误路径统一返回 `json.encode(admin.AdminErrorResponse{error: ...})`，成功路径附带 `admin_endpoint` 与可选 `admin_action` 字段。
- 内部网关通过 `InternalAdminRequest.normalize_admin_path/normalize_gateway_path` 归一化路径后再做 match 分发，禁止裸字符串比较。
