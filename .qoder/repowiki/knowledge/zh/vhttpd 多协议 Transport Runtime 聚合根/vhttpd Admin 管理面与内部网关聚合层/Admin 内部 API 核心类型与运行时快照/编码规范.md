- 跨模块访问主进程状态一律通过 `RuntimeContext` 函数指针字段注入，禁止在 admin 子模块中直接 import main 或读取全局变量。
- 对外 JSON 响应统一使用带 `pub:` 字段的 struct，并通过 `InternalAdminResponse.json` / `.error` / `.bad_request` 工厂方法构造，确保 content-type 与错误体格式一致。
- 配置型 struct（如 `AdminState`）将可变字段放在 `pub mut:` 块内，只暴露必要的可写属性，其余保持不可变。
- 字符串输入的安全处理采用显式白名单过滤（如 `sanitize_socket_label` 仅保留字母数字及 `-_.:` 并替换非法字符）。
