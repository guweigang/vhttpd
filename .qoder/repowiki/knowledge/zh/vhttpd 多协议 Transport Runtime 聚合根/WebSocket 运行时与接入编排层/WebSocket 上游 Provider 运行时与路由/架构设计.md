本模块围绕 App 扩展方法组织，按职责拆分为四个文件：
- `websocket_upstream_types.v`：声明 provider 常量（feishu / fixture / codex）及空结构体占位，作为 provider 标识的单一来源。
- `websocket_upstream_provider_control.v`：对外暴露 enabled / pull_url / on_connected / on_connecting / on_disconnected / reconnect_delay_ms / handle_message 等控制面钩子；对 fixture 直接短路返回默认值，其余转发到 `app.provider_runtime_*` 具体实现，并在 disconnected 时统一 emit `websocket_upstream.disconnected` 事件。
- `websocket_upstream_provider_runtime.v`：通过 `build_websocket_upstream_runtime_context()` 将上述钩子包装成 `ws.UpstreamRuntimeContext` 闭包，交由底层 `ws.UpstreamRuntime.run_provider` 驱动；`ensure_websocket_upstream_provider_running` 负责解析 provider/instance、检查动态 autostart 开关并启动 goroutine；`post_connect_fn` 在连接建立后根据 provider 分派握手与心跳协程（FeishuRuntimeHeartbeat / codex.WebSocketHeartbeat）。
- `websocket_upstream_send_runtime.v`：提供 `websocket_upstream_provider_send` / `_update` 两个分发入口，按 provider match 路由到 feishu_card_bridge_proxy、feishu_provider_runtime、fixture 或 codex 的具体实现，并以 `upstream.UpstreamSendRequest.normalized('feishu')` 做缺省 provider 归一化。
依赖方向：本模块仅依赖 `net.websocket`、`provider`、`upstream`、`codex`、`ws`、`feishu` 等上层包，自身不持有业务状态，所有 provider 具体逻辑委托给 `app.providers.*` 与外部 runtime 包。
