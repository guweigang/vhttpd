- 每个启动子域以 `struct XxxStartupRuntime {}` 加同名 `fn XxxStartupRuntime.xxx(app &App | mut app App)` 方法组织，通过接收 `&App` 或 `mut app App` 区分只读与可写操作。
- 对外暴露的生命周期事件统一通过 `app.emit('xxx', {key: '${value}'})` 上报，字段值一律先格式化为字符串再放入 map。
- HTTP 路由使用 veb 的 `@[get|post|...; '/path'; method]` 注解声明，handler 签名固定为 `(mut app App, mut ctx Context) veb.Result`。
- 请求追踪标识通过 `resolve_trace_id` / `resolve_request_id` 两个辅助函数集中解析，优先从 query 参数取，其次回退到 header 与上下文。
