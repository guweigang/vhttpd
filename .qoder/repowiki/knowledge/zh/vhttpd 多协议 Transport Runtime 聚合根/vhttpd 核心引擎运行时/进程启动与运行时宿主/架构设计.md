本模块是单进程 HTTP 服务器的启动与宿主层，所有文件同属 `module main`，由 `src/main.v` 作为程序入口：
- `App` 结构体组合了 `veb.Middleware[Context]`、`veb.StaticHandler`、`DataPlaneRuntime`（数据面）、`ControlPlaneRuntime`（控制面）和 `ProcessLifecycle`，并通过 `emit(kind, fields)` 统一向上游上报生命周期事件。
- 所有入站 HTTP 请求经 `proxy_get/post/put/patch/delete/head/options` 七个路由分发到 `HttpIngressRuntime.route`，实现协议无关的转发；同时 `host_builtin_runtime.v` 提供 `/health`、`/dispatch`、`/events/stream` 等内建管理端点，在 `has_http_logic_executor()` 为 false 时直接本地处理，否则走 worker 代理。
- 启动阶段按职责拆分为三个独立 struct + fn 组合：`TransportStartupRuntime.initialize` 设置 DB/Cache socket 环境变量并拉起缓存服务；`AssetStartupRuntime.mount/install_middleware/log_endpoint` 挂载静态目录并注入 cache-control 中间件；`ControlPlaneStartupRuntime.start_admin_plane` 异步启动 admin 平面并发射 `server.started` 事件。
- 依赖方向单向向外：本模块仅 import `upstream.transport`、`veb`、`veb.sse`、`dispatch`、`log`、`json`、`os`、`time`，不反向被业务逻辑引用，属于最顶层宿主。
