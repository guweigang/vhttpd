本模块由三个独立的 `module main` 文件组成，分别承担不同入口职责：
- `stream_runtime.v`：定义 `StreamRuntimeContext` 结构体及其方法（`emit`、`dispatch_open/next/close`），通过闭包持有对 `App.kernel_stream_dispatch_*` 的引用，作为上游 transport 层与内核流调度的薄封装。
- `protocol_ingress_runtime.v`：定义 `ProtocolIngressRuntime`，聚合 `OpenaiProtocolIngressPort` 与 `McpProtocolIngressPort` 两个端口实现；`try_route_http_request` 按顺序尝试各协议端点，并在 `app.pipelines.has_protocol_http_override` 存在时短路返回，体现“可覆盖”的协议接入策略。
- `generic_event_runtime.v`：实现 JSON 格式的运行时事件分发入口 `dispatch_runtime_event`，解析 `RuntimeEventDispatchRequest`，归一化 ingress/topic/name/request_id/trace_id，调用 `runtime_event_pipeline` 按 ingress + metadata 匹配或按 ID 精确选择 `PipelinePlan`，再通过 `run_transform_refs` 执行变换链，并以 `runtime.event.dispatch` / `runtime.event.dispatch_failed` 指标回传结果。
依赖方向单向向外：这三个文件仅 import 上层模块（`upstream.transport`、`veb`、`dispatch`、`runtime_plan`、`time`），不反向依赖具体协议实现，形成“运行时适配器 → 内核调度/管道”的分层边界。
