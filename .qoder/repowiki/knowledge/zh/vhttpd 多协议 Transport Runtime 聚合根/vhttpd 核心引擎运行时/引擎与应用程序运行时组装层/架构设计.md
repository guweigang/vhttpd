本模块是 vhttpd 进程内应用组装的核心，围绕两个顶层结构组织：
- `DataPlaneRuntime`（定义于 `app_composition_runtime.v`）聚合 transport、websocket、upstreams、relay、protocols、providers、engines、assets、pipelines、transformers、replacement 等运行时组件，作为数据面唯一入口；`ProcessLifecycle` 记录启动时间戳与 scheme。
- `ControlPlaneRuntime`（同文件 + `app_runtime_core_builder.v`）封装 admin、HTTP 统计、事件日志，并通过 `emit(kind, fields)` 回调统一写入 JSONL 事件日志，供上层生命周期钩子使用。
- `EngineRuntime`（`runtime_hubs.v` 中声明，`engine_runtime.v` 中实现）持有 `primary worker.WorkerState` 与 `additional map[string]&WorkerState`，通过 `dispatch_selection(name)` 按 pool 名称路由到对应逻辑执行器，并对每个 WorkerState 调用其 `logic_executor` 的 lifecycle/warmup/close，同时维护 `inflight_requests`/`served_requests` 计数并在达到 `max_requests` 时触发重启。
- `engine_runtime_builder.v` 从 `executor.LogicExecutorRuntimePlan` 与 `runtime_plan.RuntimePlan` 构建 EngineRuntime：先构造 primary，再遍历 routes / event pipelines / provider ingress pipelines 解析出 AdditionalEngineBuildTarget，去重后逐个 `resolve_additional_engine_from_plan` 生成子计划并填充 `worker_state_from_executor_plan`。
- 依赖方向单向：本模块消费 `executor`、`worker`、`server_lifecycle`、`runtime_plan`、`config` 等已实现子系统，自身不暴露对外接口，仅被上层 server_lifecycle 组合进最终进程。
