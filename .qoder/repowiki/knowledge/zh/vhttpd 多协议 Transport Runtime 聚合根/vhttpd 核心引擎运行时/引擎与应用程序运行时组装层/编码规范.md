- 对共享状态（如 ControlPlaneRuntime、EngineRuntime.primary）采用显式 `sync.Mutex` + `@lock()`/`unlock()` 手动加锁，配合 `defer { ... unlock() }` 模式保证释放。
- 可选字段访问一律使用 `or { continue }` / `or { return error(...) }` 短路风格，避免显式 nil 检查分支。
- 对外暴露的可变状态通过 `mut receiver` 方法接收可变引用，不可变查询则用 `&receiver` 只读接收者。
- 运行时指标收集集中在独立的 struct（如 `EngineRuntimeMetrics`、`HttpStats`），由专门的 `metrics()`/`stats_snapshot()` 方法聚合读取。
