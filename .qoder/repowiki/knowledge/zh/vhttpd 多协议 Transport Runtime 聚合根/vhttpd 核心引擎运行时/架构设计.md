本模块是 vhttpd 进程的运行时装配中心，按职责拆分为若干子运行时并通过 `runtime_hubs.v` 中的共享 Hub 结构体（`TransportRuntimeHub`、`ProtocolRuntimeHub`、`EngineRuntime`）进行跨层通信：
- `startup_and_hosting` 在 `main.v` 中定义顶层 `App`，注入 `DataPlaneRuntime`/`ControlPlaneRuntime`，并暴露 HTTP 代理路由到 `HttpIngressRuntime.route`。
- `engine_and_app_composition` 负责把 executor、worker、transport、protocol、provider、pipeline 等子系统组装成上述两个 Runtime，并通过 `EngineRuntime.primary/additional` 管理主/附加 worker 实例。
- `stream_and_protocol_ingress` 提供 `ProtocolIngressRuntime` 和事件分发，由 `ProtocolRuntimeHub` 持有 ingress、MCP/OpenAI/Plugin 状态，供上层控制面调用。
- `http_pipeline_runtime` 与 `command_system` 分别处理 HTTP 请求管道与 WebSocket 上游命令，二者都通过 `TransportRuntimeHub.db/cache` 访问共享持久化能力。
- `server_lifecycle_and_orchestrator` 解析配置、注册信号处理器、驱动单/多监听器启停，并把 `App` 挂入 vhttpd 服务器。
- 各子运行时之间不直接互相 import，而是通过 `runtime_hubs.v` 暴露的 Hub 结构体以及 `engine_runtime_builder.v`/`app_runtime_core_builder.v` 提供的构建函数完成依赖注入，形成“构建期装配 + 运行期 Hub 共享”的双层契约。
