- 对外暴露的配置/快照结构体使用 `pub:` 可见性块包裹字段，内部字段保持私有，仅通过方法或构造函数访问。
- 字符串键采用 `${provider}/${instance}` 形式并通过 `key_for` / `key()` 生成，空值与空白字符在入口处统一 trim_space() 处理。
- 可选字符串字段在读取时一律先 trim_space()，再与空串比较做默认值回退（如 desired_state_or_default）。
- 运行时驱动/数据库驱动通过独立的 normalize_* 函数集中归一化，将多种别名映射到单一 canonical 值。
- 通过 RuntimeContext 闭包桥接的方式替代直接 import main，使 provider 子模块与主进程解耦。
