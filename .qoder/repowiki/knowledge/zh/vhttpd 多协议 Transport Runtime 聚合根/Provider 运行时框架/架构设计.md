本模块围绕 `src/provider_runtime_hub.v` 中的 `ProviderRuntimeHub` 结构体组织：它聚合 `ProviderHost`（注册表）、`ProviderInstanceRegistry`（实例目录）以及 `codex.CodexState`/`feishu.FeishuState` 等上游状态，并通过 `provider_runtime_driver.v` 实现基于 `driver` 字段（`native`/`vjsx`）的分发——`native` 直接调用内置 Feishu 动作，`vjsx` 经 `ProviderRuntimePluginCaller` 接口转发到插件能力。

- 引导与装配：`provider_bootstrap.v` 在应用启动时按编译开关注册各 Provider，`provider_runtime_builder.v` 把配置映射为 `ProviderRuntimeSettings` 并注入 Hub；
- 运行时快照与指标：`provider_runtime_state.v` 对 feishu/codex/db/cache 做统一快照与 metrics 聚合，向上暴露 `upstream.UpstreamSnapshot`；
- 外部入口：`provider_action_adapter_runtime.v`、`provider_websocket_hook_runtime.v`、`provider_ingress_event_runtime.v`、`provider_instance_admin_runtime.v`、`provider_startup_runtime.v` 作为 HTTP/WebSocket 钩子，最终都落到 Hub 的 dispatch 路径；
- 上游控制：`provider_runtime_upstream_control.v` 通过 Hub 提供的 `provider_runtime_instances`/`snapshot` 等 API 管理上游连接生命周期。

跨子模块的统一契约是 `provider/spec.v` 定义的 `ProviderSpec`/`ProviderLifecycleCtx` 以及 `provider/types.v` 中的 `ProviderRuntimeInvocation`/`PluginCallRequest`，所有子模块围绕这两个类型进行通信。
