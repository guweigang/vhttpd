本模块由三个独立的 `module main` 文件组成，分别承担不同职责：
- `worker_backend_drain_runtime.v`：在 `EngineRuntime` 和 `App` 上扩展 `drain_engine` / `engine_drain_status` / `resume_engine` 三个方法，内部委托给 `worker.WorkerState` 的 `drain_worker_state` / `resume_worker_state` / `worker_state_drain_status`；对外通过 `app.emit('admin.worker.drain' | 'admin.worker.resume', ...)` 广播事件，返回统一的 `EngineDrainStatus`（含 engine、worker_count、draining_count、inflight_requests、ready_count、changed）。
- `worker_backend_selection_diagnostics.v`：暴露 `worker_selection_diagnostics_for_state`，对每个 socket 执行串行探测——先检查 draining/busy/process_alive，再尝试 `net.unix.connect_stream` 建立连接以验证可路由性，产出 `[]transport.WorkerSelectionDiagnostic`。
- `worker_backend_error_classifier_test.v`：仅包含一个测试函数，断言 `upstream.transport.classify_worker_backend_error` 对 queue full/timeout 两类错误返回的 HTTP 状态码与分类字符串。
依赖方向单向指向 `worker` 与 `upstream.transport`，不反向被业务逻辑调用，属于横切诊断能力。
