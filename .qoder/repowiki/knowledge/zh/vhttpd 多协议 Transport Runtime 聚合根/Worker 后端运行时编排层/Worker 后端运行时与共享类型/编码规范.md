- 对外 I/O 方法统一返回 `!T` 错误类型，并在调用链中用 `!` 冒泡，失败时直接返回而非吞掉错误。
- JSON 序列化使用 `json.encode` 写入 payload，反序列化统一走 `json.decode(Type, raw)` 配合帧长度读取。
- 状态字段通过 `pub mut:` 显式标注可变字段，访问共享状态前必须显式 `@lock()` / `unlock()`，并使用 `defer unlock()` 模式保护快照类操作。
- 对可选配置采用零值安全处理（如 `status <= 0` 回退到 200、`read_timeout_ms > 0` 才设置超时），避免 nil/空指针分支。
