- CSS 主题通过 :root 中定义的 CSS 变量统一管理（--bg、--accent、--accent2、--accent3、--border 等），避免硬编码颜色值
- 页面区块统一使用 .section + .container 包裹，配合 .section-label、.section-title、.section-desc 三段式标题结构
- 卡片类组件使用 feature-card 基础样式，通过 feature-icon.teal/indigo/orange 变体区分类型
- 代码块与终端模拟统一使用 code-block / terminal-body 样式，内部通过 key/val/comment/section-name 语义化 span 着色
- 网格布局通过 .grid-2/.grid-3/.grid-4 复用，基于 CSS Grid auto-fit + minmax 实现响应式列数自适应
