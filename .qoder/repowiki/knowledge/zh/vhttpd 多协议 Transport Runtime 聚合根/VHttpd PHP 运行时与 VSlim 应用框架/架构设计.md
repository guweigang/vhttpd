模块以 `php/package/composer.json` 定义的 PSR-4 命名空间为边界，按职责拆分为三个顶层命名空间：
- `VHttpd\*`（src/VHttpd）：运行时基础设施层。`PhpWorker/Server.php` 通过 Unix socket 监听 vhttpd 宿主的 JSON 帧请求，解析 `app.php` 返回的 `[ 'http' => callable, 'websocket_upstream' => callable ]` 结构并分派；`Wire/FrameCodec` 与 `JsonClient` 封装 4 字节长度前缀 JSON 帧协议；`DbGateway/*`、`Cache/Client`、`WordPress/*` 作为面向宿主的客户端网关。
- `VSlim\*`（src/VSlim）：应用框架层。`App/Psr7Adapter` 将 PSR-7 请求适配到 `VSlim\App`；`Stream/*` 提供纯 PHP 流式响应（SSE/ndjson/Ollama 客户端），在扩展模式由 `vslim.so` 的 `VSlim\Stream\Response` 替代；`App\Feishu\BotApp/BotHandler/BotAdapter` 实现飞书消息/事件到 Command 的 typed dispatch；`Mcp/App` 和 `WebSocket/App` 分别承载 MCP 工具集与 WebSocket 会话。
- `VPhp\Provider\Codex\*`：第三方 Provider 适配层，把外部 Codex 协议转换为内部 Feishu Message/Notification/Parser/Response。

入口约定：`php/app.php` 返回包含 `http` 与 `websocket_upstream` 键的可调用数组，`Server::normalizeApp` 据此自动路由；`bin/vphp-worker` 与 `bin/vphp-worker-client` 是 composer bin 可执行文件，用于独立启动 worker 进程或向已有 worker 发送调试帧。

依赖方向单向向下：应用代码（`app/MyFeishuBot.php`）→ VSlim → VHttpd 运行时 → 宿主 socket 协议；测试位于 `package/tests/`，覆盖 DB/Cache/Worker 帧协议与 WordPress 生命周期。
