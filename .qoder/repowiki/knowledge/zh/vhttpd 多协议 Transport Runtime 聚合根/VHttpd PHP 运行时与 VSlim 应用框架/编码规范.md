- 所有公共类使用 `declare(strict_types=1)` 并以 `final class` 形式暴露，避免被继承篡改核心行为。
- 对外部输入一律采用 `array<string,mixed>` 类型注解并在入口处做 `is_array`/`json_decode(JSON_THROW_ON_ERROR)` 校验，错误统一包装为 `RuntimeException` 抛出。
- 通过 `getenv('VHTTPD_*')` 注入运行时参数（socket、父进程 PID、app 路径等），而非构造函数显式传参，保持 CLI 与扩展两种部署模式一致。
- 流式响应统一返回 `VHttpd\PhpWorker\StreamResponse` 实例，由 Server 层检测并走 `writeStreamResponse` 分支，普通响应则经 `normalizeResponse` 标准化为 JSON 帧。
- 飞书领域按 provider/app 分层：`VHttpd\Upstream\WebSocket\Feishu\Message/Event/Command` 描述底层协议对象，`VSlim\App\Feishu\BotApp/BotHandler` 负责 typed dispatch，业务 Bot 仅继承 `AbstractBotHandler` 实现回调。
