- 所有对外可见的请求/事件/快照结构体使用 `pub:` 字段声明，并通过 `from_*` / `normalized` 方法做入参归一化
- 需要并发访问的共享状态（如 registry.sessions）一律用 `sync.Mutex` 保护，读写路径首尾配对 lock/unlock
- Provider 实现遵循「发送端构造 UpstreamSendRequest → 调用 provider.Send → 返回 UpstreamSendResult」的固定模式
- 错误路径统一通过 rt.note_error() 计数 + emit('http.stream.error', {...}) 上报，再由 write_error 按 stream_type 选择 SSE done 或 text/plain 响应
