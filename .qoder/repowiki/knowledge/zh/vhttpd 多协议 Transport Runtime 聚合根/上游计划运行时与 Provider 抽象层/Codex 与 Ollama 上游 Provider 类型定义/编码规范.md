- 结构化状态通过 `pub mut:` 块显式标记可变字段，配合只读 getter（如 `is_connected`、`current_thread_id`）对外暴露不可变视图。
- 对共享状态读写统一走 `CodexState.snapshot()` / `update()` 加锁入口，避免直接操作内部 map 字段。
- JSON 解析优先采用 `jsonutils.has_any_top_level_key` + 自定义 `RpcField.string/raw` 字符串扫描，而非完整反序列化，以规避每帧全量解析开销。
- 调试信息通过 `RpcDebug.log(label, raw)` 包装，在 `prod` 构建下自动静默，开发环境截断到固定长度再输出。
- 多实例配置通过 `normalize_instance` 将空串与 `default` 归一化为 `main`，再由 `for_instance` 派生子实例并继承基础配置。
