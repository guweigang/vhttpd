本模块由两个并列的 V 语言子包组成，均位于 `src/upstream/provider/` 下，作为上层 provider 框架的数据契约层：
- `codex` 子包按职责拆分为四个文件：`types.v` 集中声明 `ProviderRuntime`、`CodexState`、`PendingRpc`、`ReadFallback`、`AdminConfigSnapshot` 等核心结构体及其方法；`rpc.v` 实现基于字符串扫描的轻量 JSON-RPC 分类器（区分 request/notification/response）、字段提取（`RpcField.string/raw`）、调试日志与 WebSocket 心跳；`runtime.v` 封装流目标管理（`stream_map`、`thread_stream_map`）、错误风暴抑制（`err_bursts`/`err_pending_flushes`）与 read fallback 调度；`state.v` 提供多实例工厂 `for_instance` 以及带互斥锁的 `snapshot/update` 访问入口。
- `ollama` 子包仅含 `types.v`，定义 Ollama NDJSON 行结构 `OllamaNdjsonRow` 及 `field(path)` 路径选择器。
依赖方向单向向下：上层 provider 实现依赖本模块暴露的 struct 与方法，本模块不反向 import 任何 provider 实现，也不持有外部网络连接的具体逻辑（仅保存 `&ws.Client` 引用）。
