模块以 `types.v` 中的 `FeishuState` 为全局单例核心，集中持有 app 配置映射、每应用 `ProviderRuntime` 连接状态、`StreamBuffer` 流式缓冲以及 card bridge 的 WebSocket 客户端池；`state.v` 提供按 name 懒加载 runtime 的生命周期方法（ensure/note_*），并聚合多实例的 chats_snapshot 与 totals 指标。

- 协议层：`proto_frame.v` + `helpers.v` 定义 RuntimeProtoHeader/Frame、控制帧类型常量，配合 `callback_crypto.v` 完成回调签名校验。
- HTTP 层：`http.v` 通过 `HttpLane`/`ControlHttpLane` 串行化所有对外请求，并在 `$if test` 编译期开关下注入 `http_test_stub` 模拟响应，避免真实网络依赖。
- API 封装：`api.v` 将发送/更新/图片上传/租户令牌等飞书 REST 端点抽象为 `SendMessageRequest`/`UpdateMessageRequest`/`UploadImageRequest` 等方法族，统一生成 URL、payload 与 multipart 表单。
- 内容构建：`message_content.v` 根据 msg_type 拼装 text/image/file/media/post/interactive 等 content JSON，并提供 streaming_card / render_final_card 支持长文本分段推送。
- 事件处理：`event_summary.v` 用 `x.json2` 从原始 payload 提取扁平化的 `RuntimeEventSnapshot.summary_from_payload`，并通过 `should_dispatch_upstream` 过滤系统事件。
- 桥接：`bridge.v` 定义 `BridgeEnvelope`/`BridgeDispatchRequest`/`BridgeProxyResult` 等跨进程协议常量与结构体，由 `endpoint.v` 暴露给外部 gateway 调用。

依赖方向：本模块仅向上暴露 `FeishuState` 方法与快照类型，向下依赖 `config`、`executor`、`upstream`、`command` 等上层包，不反向引用其他 provider。
