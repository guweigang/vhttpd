- 对外 HTTP 调用统一经 `http_fetch`/`control_http_fetch`/`http_post_multipart_form` 三入口，内部用 `lock state_mut.http_lane` 串行化，并在 `$if test` 分支下走 `http_test_stub` 返回固定 JSON 响应。
- 运行时指标变更采用 `note_*` 命名（note_connecting/note_connected/note_disconnected/note_frame/note_ack/note_send），先 ensure 对应 runtime，再 update_runtime 写回，保证并发安全。
- 请求对象（SendMessageRequest/UpdateMessageRequest/UploadImageRequest）均提供 `resolve_params()` 做参数归一与校验，再由 `api_url`/`api_payload`/`multipart_config` 等派生函数构造最终 HTTP 请求。
- 事件摘要通过 `JsonField.map`/`JsonField.string` 在 `header/event/action/message/sender/context` 多层嵌套中逐级 fallback 取值，空值一律回退到空字符串而非 panic。
- 流式输出使用 `StreamBuffer` 按 `stream_buffer_rollover_runes=4200` 切分，首段用 `streaming_card` 追加“继续输出”提示，尾段用 `render_final_card` 渲染完整 markdown 或模板。
