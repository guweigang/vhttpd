本模块由三个职责清晰的文件组成：
- `upstream_plan_delivery_projection.v`：纯函数层，把 `transport.WorkerUpstreamPlanFrame` 转换为 `dispatch.DeliveryOutcome`（目标形如 `upstream:<name/id>`），根据 `output_stream_type` 决定 `sse`/`text` 及默认 `content-type`，并把 plan 的 meta/response_headers 透传到 outcome。
- `upstream_runtime_registry.v`：维护进程内活跃会话表 `sessions[req_id] -> UpstreamRuntimeSession`，通过 `sync.Mutex` 保护，提供 register/unregister/note_error/snapshot/totals 等统计与快照能力；`build_upstream_runtime_context()` 把 App 上的 `app.upstreams` 和 `app.emit` 注入到回调闭包中。
- `upstream_runtime.v`：核心编排入口 `execute_plan`，先校验 plan、调用 registry.register 并用 defer 保证 unregister，再根据 fixture_path 走 `execute_fixture` 或 `execute_http`，统一处理错误写入、SSE done 帧、HTTP chunked 尾部以及最终 emit 指标；`UpstreamIoBridge` 把 `worker.WorkerHttpStreamWriter` 适配为 `upstream.Io` 接口。
依赖方向单向：projection → runtime → registry → upstream.transport / worker / veb，registry 不反向依赖 runtime。
