- 对外暴露的 API 采用 `(mut app App) xxx()` 包装器，内部通过 `app.build_upstream_runtime_context()` 构造带闭包的 `UpstreamRuntimeContext`，再由 context 转发到具体实现，避免直接持有全局状态。
- 共享可变状态（`UpstreamRuntimeRegistry.sessions`、计数器）一律用 `sync.Mutex` + `defer { registry.mu.unlock() }` 模式保护，读多写少场景在 snapshot 中先拷贝再排序切片。
- 错误路径统一通过 `rt.note_error()` 计数、`rt.emit('http.stream.error', ...)` 上报、再调用 `write_error` 写出 502 响应，确保可观测性一致。
- `UpstreamRuntimeContext` 以函数指针字段 (`register_fn`/`unregister_fn`/`emit_fn`/`snapshot_fn`) 解耦上层 App，便于测试时注入 mock 行为。
