本模块以 `module transport` 统一暴露，按职责拆分为若干独立文件：
- `worker_protocol.v`：集中声明所有跨进程 JSON 帧结构体（WorkerRequestPayload、WorkerStreamFrame、WorkerWebSocketFrame、WorkerMcpDispatchRequest 等），是上层调度器与 worker 子进程通信的契约。
- `worker_framing.v`：实现二进制帧 I/O（4 字节大端长度前缀 + JSON body）以及 HTTP→JSON 请求编码（encode_worker_request）、查询串/cookie/header/server 映射工具，并封装 try_decode_stream_start / try_decode_upstream_plan 等弱类型帧解析入口。
- `fastcgi.v`：纯 FastCGI 协议实现，手动拼装 FCGI_BEGIN_REQUEST/FCGI_PARAMS/FCGI_STDIN/FCGI_END_REQUEST 记录并通过 unix.StreamConn 与 php-cgi 交互，将 stdout 中的 CGI HTTP 响应反序列化为 WorkerResponse。
- `worker_pool.v`：基于 os.Process 管理外部 worker 子进程生命周期，通过全局 ManagedWorkerProcessRegistry 注册 child pid，提供 start/build_slot/stop/restart_backoff_ms 及 wait_for_socket 启动等待；支持 `{socket}` 占位符与 --socket 自动注入，向进程组发送 SIGTERM/SIGKILL 优雅退出。
- `session_handle.v` / `transport_handle.v`：轻量上下文对象，从不同来源（websocket_upstream、stream_dispatch、mcp_dispatch、websocket_dispatch）构造 SessionHandle，标记 role/provider/transport/stream_type/source/instance 供上层追踪。
- `error_classifier.v`：根据错误消息文本归类为 502/503/504 及 error_class 标签，供上层统一返回。
依赖方向：各文件均只依赖标准库与 net.unix/net.http/json/log，彼此之间通过共享 struct 和函数名（如 WorkerFrameCodec、WorkerHttpRequestCodec）形成松耦合，无循环引用。
