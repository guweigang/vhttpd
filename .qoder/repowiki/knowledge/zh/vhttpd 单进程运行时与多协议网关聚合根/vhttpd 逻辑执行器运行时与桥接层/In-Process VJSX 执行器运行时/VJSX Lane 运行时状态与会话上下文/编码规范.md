- 对外暴露的 receiver 方法均以 `if isnil(e.state) || ... { return }` 做空指针与边界守卫，再取局部 `mut state := e.state` 持有引用。
- 对 `state` 的写操作统一采用 `state.mu.@lock()` + `defer state.mu.unlock()` 模式，并在循环遍历 `state.lanes` 时按 `id` 匹配定位目标 lane。
- 任务结构体一律配套一个 `*TaskSlot` 结构体，内部包含 `sync.Mutex`、结果字段与 `ready` 标志，供异步回调安全填充。
- 可取消的定时唤醒使用 `generation u64` 配合 `wake_at_ms i64` 双重比较来丢弃过期条目，避免竞态下的重复唤醒。
