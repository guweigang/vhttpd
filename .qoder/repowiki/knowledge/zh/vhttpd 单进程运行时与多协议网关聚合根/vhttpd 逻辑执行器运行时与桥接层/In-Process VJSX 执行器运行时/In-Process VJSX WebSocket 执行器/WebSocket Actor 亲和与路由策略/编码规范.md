- 所有外部输入字符串统一经 `trim_space().to_lower()` 后再做匹配或比较，避免大小写与空白差异导致的行为不一致。
- source/scope/fallback/event 等枚举型配置项通过独立的 `normalize_*` 函数集中归一化，未识别值走默认分支而非报错。
- 从 `vjsx.Value` 解析结构化决策时采用逐项 `get('field')` + `is_undefined()/is_null()` 检查，并用 `defer { ... free() }` 释放临时值，缺失字段保持零值。
- 对共享状态读写一律先判空 `isnil(e.state)`，随后 `state.mu.@lock()` / `unlock()` 保护 map 访问，失败路径返回带错误码的 error。
