- 每个宿主方法统一实现为 `InProcVjsxHostApi.<name>_builder(mut state, idx)` 返回 `vjsx.HostValueBuilder`，再由 `builder` 聚合注册到 `vhttpdHost` 命名空间下。
- JS→Go 调用一律采用单参 JSON 字符串 + 对应 `InProcVjsxHost*Request` 结构体 `json.decode` 解析，错误时返回带 `error` 字段的 `InProcVjsxHost*Response` JSON 字符串。
- 访问共享状态前必须 `state.mu.@lock()`，并在持有期间仅拷贝需要的字段（如 `app_ref`、`request_ctx`），随后立即 `unlock()`，避免长时间持锁。
- 对外部资源（网络、文件系统）调用前先检查 `state.facade.config.enable_network` / `enable_fs` 开关，禁用时直接返回空/错误响应而非 panic。
- 异步回调闭包统一捕获 `[mut state, idx] (ctx &vjsx.Context)` 三件套，通过 `idx` 定位当前 lane/host，再根据 `state.hosts[idx].request_ctx.active` 区分请求期与空闲期上下文。
- 生命周期中失败路径遵循 `session.close() → os.rmdir_all(temp_root) or {} → return error(...)` 三段式清理模式，确保临时目录与 JS session 成对释放。
