本模块为 `worker` 子包（`src/worker/*.v`）加一个独立的入口文件 `src/worker_backend_admin_runtime.v`，共同构成 Worker 后端运行时的核心：
- `types.v` 声明 `WorkerBackend` 接口及默认实现 `PhpWorkerBackend`，并通过组合持有 `[]transport.ManagedWorker`；`WorkerBackendRuntime` 聚合后端实例、Unix socket 列表、轮询索引、队列参数与统计量，`WorkerState` 再在其之上叠加互斥锁、执行器选择（`executor.WorkerBackendMode` / `executor.LogicExecutor`）、生命周期与流式分发开关。
- `connection.v` 封装单个 `unix.StreamConn` 到后端的读写，提供 `write_payload`、`read_stream_response`、`read_mcp_response`、`read_websocket_*` 等高层方法，内部委托给帧编解码器。
- `frame_codec.v` 实现定长 4 字节大端长度头 + JSON body 的二进制帧协议，所有读路径先校验 size ∈ (0, 16MB]，再 `json.decode` 到 `upstream.transport` 中的具体响应结构体。
- `http_writer.v` 面向下游客户端 TCP 连接，提供 HTTP/1.1 chunked 分块、SSE (`id/event/data/retry`) 帧以及 WS 相关写辅助，屏蔽底层 `net.TcpConn` 细节。
- `worker_backend_admin_runtime.v` 以 `main` 模块形式挂载在引擎侧，通过 `EngineRuntime.restart_worker_by_id` / `restart_all_workers` / `admin_snapshot` 暴露管理 API，并调用外部 `ps -o rss=` 获取进程 RSS 作为指标。
依赖方向单向向外：本模块仅依赖 `upstream.transport`、`executor`、`sync`、`net.unix`、`net`、`json`、`os`、`time`，不反向依赖上层路由或调度逻辑。
