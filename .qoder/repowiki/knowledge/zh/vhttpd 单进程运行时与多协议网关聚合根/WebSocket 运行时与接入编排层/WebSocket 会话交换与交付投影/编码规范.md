- 通过 `websocket_context_with_session(ctx, fallback)` 在构造 Exchange 前统一回填 session_id，fallback 优先级为 frame.id → frame.request_id → ctx.request_id → 'websocket'。
- 所有 Exchange 的 identity 均由 `websocket_exchange_identity(session_ctx, suffix)` 生成，suffix 根据 kind 固定为 'open'/'close'/'message'，保证同一会话内父子 trace 关系一致。
- metadata 统一写入 `websocket.source`（worker 或 runtime）、`websocket.event`、`websocket.path`、`websocket.conn_id` 等标准键，区分来源与事件语义。
- DeliveryOutcome 一律使用 `dispatch.session_plan_outcome_with_status(101, 'websocket:${req_id}', {'upgrade':'websocket'}, metadata)` 构造，确保 HTTP 升级响应格式统一。
- `WebSocketRuntime` 对 `ws.HubState` 的访问全部通过方法代理，写路径显式加 `@lock()/defer unlock()`，读路径直接调用 `hub_snapshot` 等封装函数。
