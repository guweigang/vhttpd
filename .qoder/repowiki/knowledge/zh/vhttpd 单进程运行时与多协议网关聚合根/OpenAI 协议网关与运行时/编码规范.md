- 所有 handler 函数均以 `(mut app App)` 或 `(app &App)` 方法形式挂载到宿主 `App`，并在入口处用 `OpenAIErrorResponseWriter.write(...)` 统一返回错误响应。
- 计划字段校验采用 `validate_*` 静态方法链（`validate_method`/`validate_path`/`validate_stream_mode`/`validate_response_codec`/`validate_output_protocol`/`validate_mapper`），失败时通过 `plan_error(code, message)` 返回带前缀的错误字符串。
- 上游后端 kind 为 `executor` 的请求走 `OpenAIProxyRuntime.executor_*` 分支，否则走 HTTP 直连；`stream_mode == 'mapped'` 时额外经过 `OpenAIResponseBuilder.map_once_response` 转换。
- 从 JSON body 提取字段一律使用 `json2.decode[json2.Any](body) or { return default }` 模式，避免显式错误处理。
- Responses 写入后通过 `OpenAIResponseRecord.from_plan` 构造记录并调用 `app.protocols.openai.responses.set_with_ttl` 存入内存状态存储，读取时先查缓存再回源。
