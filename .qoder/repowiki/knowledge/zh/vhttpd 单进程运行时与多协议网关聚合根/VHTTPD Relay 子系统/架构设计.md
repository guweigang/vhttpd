本模块由五个子域按数据流串联：
- `wire_protocol` 定义 JSON WireFrame 编解码与 ResponseCompletionOutcome 合并；
- `core_runtime` 维护 Agent 连接生命周期，委托 `messaging_core`（ChannelRegistry/SessionRegistry/Carrier）完成注册表与传输抽象；
- `forwarding` 在 runtime 层统一编排入站注册、出站投递计划与通道级转发；
- `registration_snapshot` 提供握手注册协议、只读快照导出以及 WireFrame→Exchange 的投影；
- `pipeline_runtime` 基于 runtime_plan 驱动变换链，并通过终端适配器或 MCP 上游产出结果。
顶层入口 `relay_runtime_builder.v` 暴露 `relay_runtime_with_diagnostics_from_plan`，从 `runtime_plan.RuntimePlan` 构造 `relay.Runtime`；`relay_pipeline_runtime.v` 作为应用侧桥接层，把 `dispatch.Exchange` 转换为 `WireFrame` 再经 carrier 发送，并将发送结果回填为事件字段。子模块之间通过 `relay` 包导出的 `Runtime`、`WireFrame`、`CarrierSendResult` 等契约通信，无直接互相 import。
