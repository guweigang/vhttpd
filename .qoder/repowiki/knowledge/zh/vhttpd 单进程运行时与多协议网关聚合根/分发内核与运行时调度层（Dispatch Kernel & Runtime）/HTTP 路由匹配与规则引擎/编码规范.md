- 匹配函数采用“逐项短路返回 false”的守卫式写法，任一条件失败立即返回，成功时再在末尾返回 true。
- 字符串列表匹配统一封装为 `match_string_list`，并通过 case_insensitive 参数控制是否 to_upper 比较，避免在每个调用处重复处理大小写。
- 路径模式以 `*` 作为通配符，分别用 starts_with('*') 与 ends_with('*') 分支处理前缀/后缀匹配，纯 `*` 表示全匹配。
- 对外暴露的 struct 使用 V 语言的 pub: 块显式声明公共字段，内部辅助函数保持 fn 而非 pub fn，仅导出必要 API。
