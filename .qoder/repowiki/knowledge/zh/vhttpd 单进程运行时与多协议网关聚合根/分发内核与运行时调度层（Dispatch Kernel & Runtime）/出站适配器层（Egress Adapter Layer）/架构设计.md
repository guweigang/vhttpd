本模块位于 dispatch 子包内，以 adapter.v 为契约核心：声明 `EgressAdapter` 接口（id/capabilities/warmup/deliver/close）以及 `DeliveryOutcome`/`DeliveryOutcomeKind` 统一产出结构体，并通过一组工厂函数（response_outcome、file_outcome、accepted_event_outcome、stream_plan_outcome、session_plan_outcome、relay_delivery_outcome、delivery_failure_outcome）构造不同交付语义的 Outcome。

三个具体适配器文件各自实现同一接口，形成“一个 struct + 同名构造函数 + id/capabilities/warmup/deliver/close 方法”的统一形态：
- fixed_response_adapter.v：返回预置 status/headers/body 的 response 结果；
- reject_adapter.v：返回 delivery_failure 结果，默认 403/rejected；
- relay_delivery_adapter.v：将 Exchange 的 identity/pipeline/request/query 等上下文注入到 metadata，并透传 headers，产出 relay_delivery 结果，支持 completion_mode 与 timeout_ms 配置。

依赖方向单向：各适配器仅依赖 adapter.v 中暴露的公共类型与构造器，不反向引用上层调度逻辑，从而让上层 dispatcher 通过统一的 EgressAdapter 抽象编排多种出站策略。
