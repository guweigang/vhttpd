本模块按职责拆分为四个子域，通过共享类型与接口在启动链路中串联：
- `config_and_runtime_plan` 负责读取 TOML 配置（含 CLI 覆盖与 include），将 V1/V2 schema 编译为统一的 `runtime_plan.RuntimePlan`；
- `state_stores` 定义泛型 KV 接口并提供内存实现，`admin_state_store` 在此基础上叠加基于 JSON 文件的命名空间事件日志持久化；
- `runtime_utils` 暴露 JSON 顶层键探测、运行时日志级别切换，以及通过 Unix Domain Socket 对外提供的内存缓存与数据库代理；
- 上层 HTTP 服务在启动时依次调用 config 加载 → 编译 RuntimePlan → 初始化 state_store → 注入 runtime_utils 中的日志/缓存/DB 代理，形成单向依赖链，避免循环引用。
