- 配置项在 TOML 中使用 `@[toml: 'snake_case']` 标签声明驼峰字段名到 snake_case 键的映射，保持 Go 风格字段名与配置文件命名解耦。
- V2 配置解析采用「先 decode 再 validate」模式：`decode_v2_config_strict` 用 `toml.Doc.decode[V2Config]()` 反序列化，随后由 `validate_*` 系列函数遍历 `map[string]toml.Any` 根节点，拒绝未列入允许白名单的未知键。
- 可选值读取统一封装为 `toml_string_from_map` / `toml_int_from_map` / `toml_bool_from_map` 等 helper，以 `(entry[key] or { toml.Any(default) }).string()` 形式安全取值，避免空指针。
- CLI 覆盖一律通过 `CliArgs.has` + `CliArgs.string_or|int_or|bool_or|string_list_or` 三件套判断存在性后再覆写对应 `PlanOptions` 桶，保持覆盖逻辑可测试且无副作用。
- 跨组件引用统一使用 `parse_ref('domain:id')` 解析为强类型的 `ResourceRef`，禁止直接使用裸字符串拼接，错误码前缀统一为 `plan_ref_`。
- V1→V2 兼容层在 `compile_v1_runtime_plan` 中始终设置 `source.compatibility = true`，并在 `PlanDiagnostic` 中以 `legacy_schema`/`compile_only_paths`/`legacy_magic_executor` 等 code 标注迁移提示，供上层展示。
