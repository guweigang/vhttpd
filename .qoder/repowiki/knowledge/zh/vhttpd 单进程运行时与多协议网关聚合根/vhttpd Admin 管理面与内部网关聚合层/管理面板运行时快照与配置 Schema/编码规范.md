- Schema 字段统一通过 `schema_field(name, label, type_, required, default, ref_domain, options, description)` 工厂函数构造，避免手写 struct literal。
- 可复用 kind 通过工厂函数生成：`adapter_kind(id, label, extra_fields)`、`policy_kind(id, field_names)`、`relay_fields(mode)`、`transform_fields(kind, engine_required)`，再在对应 domain 中以数组字面量组合。
- HTTP 路由使用 veb 的 `@['/path'; method]` 注解声明，并在处理函数开头检查 `app.control_plane.admin.on_data_plane`，未启用时返回 404 文本响应。
- Builder 类采用 `ensure_app(app_id)` + `update_app(app_id, next)` 的两步更新模式，先惰性创建 app 条目，再追加子项后写回。
- 所有对外返回的列表在 `finish()` 或各自 add 方法中对 id 进行稳定排序，保证输出顺序确定性。
