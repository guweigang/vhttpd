- 所有 HTTP 分支路径均以 `dispatch.EgressAdapter(dispatch.fixed_response_adapter('route/<tag>', status, headers, body))` 构造终端适配器，再经 `render_http_terminal_adapter` 统一渲染，错误码与 tag 命名采用 snake_case 的 route 前缀。
- 对外暴露的函数以 `(mut app App)` 或 `(rt PipelineRuntime)` 形式绑定到全局 `App`/`PipelineRuntime` 实例，保持无状态运行时对象风格。
- 结构化日志通过 `log.info/warn('[http] ⇠ pipeline ...')` 格式输出，固定包含 `trace_id`、`request_id`、`pipeline_id` 等可追踪字段。
- 上传完成后通过 `app.emit('upload.completed', fields)` 发布事件，并可选调用 `dispatch_upload_completed_transforms` 与 `dispatch_upload_completed_vjsx` 两条后置链路，失败时分别 emit `*_transform_failed` / `*_dispatch_failed` 事件。
